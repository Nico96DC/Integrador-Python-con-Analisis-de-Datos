# Trabajo Integrador: Python, POO y Análisis de Datos

## Descripción del Proyecto
Este repositorio contiene el trabajo final integrador del curso de "Programación en Python orientado al Análisis de Datos" (realizado en 2022). El proyecto está dividido en tres módulos principales que demuestran diferentes competencias en el lenguaje Python:

1. **Programación Orientada a Objetos (POO):** Desarrollo de un sistema de gestión básico para una bicicletería. Incluye el modelado de las clases `Bicicleteria` y `Bicicleta`, encapsulamiento de atributos (ganancias, ventas, precios) y creación de métodos para la simulación de compra y venta de unidades.
2. **Manejo de Archivos (JSON):** Procesamiento de estructuras de datos complejas (diccionarios) y persistencia de la información mediante la creación y exportación de un archivo `super_heroes.json` con su correcta indentación.
3. **Análisis de Datos:** Ingesta y exploración del reconocido dataset de pasajeros del Titanic (`train.csv`). Uso de librerías especializadas para la manipulación de datos, resolución de consignas estadísticas y visualización.

## Tecnologías y Librerías Utilizadas
*   **Python:** Lenguaje base, creación de scripts, lógica de clases (POO) y diccionarios.
*   **Módulo JSON:** Para la lectura y escritura de archivos estructurados.
*   **Pandas:** Manipulación, limpieza y análisis exploratorio del dataset del Titanic mediante *DataFrames*.
*   **NumPy:** Operaciones y cálculos estadísticos eficientes.
*   **Matplotlib:** Generación de gráficos para la visualización de los datos analizados.
*   **Jupyter Notebook:** Entorno de desarrollo utilizado para integrar el código, las visualizaciones y las respuestas (`.ipynb`).

## Archivos del Repositorio
*   `[Nombre de tu archivo].ipynb`: Cuaderno principal con el código fuente en Python de los 3 ejercicios, visualizaciones y comentarios.
*   `train.csv`: Dataset original con la información de los pasajeros del Titanic utilizado para el Ejercicio 4.
*   `super_heroes.json`: Archivo generado automáticamente por el script como resultado del Ejercicio 3.

## Cómo visualizar el proyecto
Para ver el código, la lógica de las clases y los gráficos sin necesidad de instalar nada, simplemente haz clic en el archivo `.ipynb` dentro de este repositorio. Alternativamente, puedes clonar el repositorio y ejecutarlo localmente utilizando Jupyter Notebook, Google Colab o Visual Studio Code.
